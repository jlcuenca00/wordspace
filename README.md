# Wordspace

A typing test and enhanced writing experience built around a simple idea: **complex underneath, quiet on the surface.**

## Foundation
- Editorial typography-first responsive interface
- Typing test with live character states, WPM and accuracy
- Distraction-free writing room
- Automatic local draft persistence
- Library foundation
- React + Vite

## Roadmap
Themes, test modes, detailed statistics, writing modes, passages, personalized weakness practice, custom themes, and optional account/cloud sync.

## Run
```bash
npm install
npm run dev
```
